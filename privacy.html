本めぐり
プライバシーポリシー

本をつなぐ株式会社（以下「運営者」）は、本屋と図書館をめぐる位置ゲーム「本めぐり」（https://meguri.tsunagubooks.com/。以下「本アプリ」）で扱う情報について、次のとおり定めます。本アプリを始めるとき（最初の画面）に、このポリシーに同意していただきます。

第1条　本アプリの考え方

本アプリには、会員登録やログインがありません。名前・メールアドレス・電話番号・住所は、うかがいません。

スタンプ・本のカード・メモ・本の名前・位置（いまいる場所や、本を読んだ場所）・ハンドルネーム・自分のアイコン（絵や画像）は、利用者のスマートフォンの中だけに保存し、運営者には送りません（第2条6の引き継ぎコードを使ったときは、暗号にして24時間だけ預かります。運営者は中身を読めません）。読書の記録は第2条2に書いた一部だけを、本のカードは第2条3に書いた「店と本の番号と日付」だけを送ります。

第2条　運営者に届く情報

運営者に届くのは、次の情報だけです。いずれも、本アプリが作る名前のない端末の番号（ランダムな文字列）と、本アプリの版と一緒に届きます。

  1. 参加の記録（本アプリを使うあいだ、いつも）：スタンプを押した店の番号、日付と時（分は残しません）、店の近くで押したか、参加したイベント。位置（座標）は送りません。
  2. 読書と使い方の記録（本アプリを使うあいだ、いつも）：読書をした日付と時（分は残しません）、読んだ長さ、読んだ場所の種類（移動読書・本屋や図書館のそば・その場で）、移動読書の距離（1km単位）、本をえらんでいたか、あとから長さを選んだか。本を読み終えた日、本の里帰りをした日、「1冊の旅」を開いたりシェアしたりした日。本アプリを開いた日（1日1回）と、どこで開いたか（SNSなどのアプリの中・ブラウザ・ホーム画面のアイコン・パソコンのどれか）。本の名前・本を読んだ場所（座標）・どの店のそばで読んだかは送りません。
  3. 出会った本の記録（本アプリを使うあいだ、いつも）：本のカードを作ったときの、店の番号・本の番号（ISBN）・日付。端末の番号はつけないので、誰のカードかは運営者にもわかりません。
    加えて、プロフィールで答えた「世代」と「性別」を、本の番号（ISBN）と月だけと一緒に、別に送ります（カードを作ってから時間をおいて送ります）。こちらには店の番号・日付・端末の番号をつけません。設定の「出会った本に世代と性別を添える」で止められます。
  4. 店の情報の報告（利用者が送ったとき）：店の番号、報告の種類（閉店・名前の違い・地図にない店）、店の名前、書いたひとこと、地図にない店はその店の場所。
  5. プロフィール（本アプリを始めるときか、はじめてスタンプを押した次の日など、使い始めて間もないうちに入れていただきます）：世代、性別、1か月に買う本の冊数、本屋さんに行く回数、よく読むジャンル、本を選ぶきっかけ、本を手に入れるところ、住んでいる都道府県、本アプリを知ったきっかけ。名前（ハンドルネーム）以外の答えを、統計データとして使います（ハンドルネームは送りません）。性別は「答えない」も選べます。中学生以下の方は、保護者の方と相談してから入れてください。
  6. 引き継ぎコード（利用者が使ったときだけ）：機種変更などで記録を移すとき、端末の記録を暗号にして、24時間だけ預かります。暗号を解く鍵はコードの中だけにあり、運営者には届きません（運営者は中身を読めません）。受け取ると、すぐに中身を消します。
  7. 通信のための情報：送られてきた IP アドレスは、使いすぎを防ぐために、その日だけの記号に変えて持ちます（IP アドレスそのものは残しません）。また、サーバー会社の決まりにより、サーバーの通信の記録（IP アドレス・日時・開いたページ）が一定のあいだ残ります。

第3条　使う目的

  1. イベントの運営（参加の人数を数える、限定の枠を付ける、書店員さんの1冊の書名と写真を、その店でスタンプを押した人にだけ見せる。このとき、端末の番号と店の番号で、その店で押した記録と照らし合わせます）
  2. 地図の店の情報を正しくする
  3. 本アプリの改善（読書の機能がどのくらい使われているか、続いているかを見る など）
  4. 本屋さん・出版社・著者への報告や、読書と本屋についての調査・発信。このとき使うのは人数の集計（例：「20代が○人」「この店でこの本に出会った人が○人」「この本に出会った人は30代の女性が多い」）だけで、ひとりひとりの記録や答えは出しません。店ごと・本ごとの集計と、本と世代・性別を組み合わせた集計は、10人以上いるときだけ使います。

第4条　第三者への提供

運営者は、法令にもとづく場合を除き、ひとりひとりの記録や答えを第三者に渡しません。

第3条4の人数の集計（ひとりが特定されない統計）は、本屋さん・出版社などに、有償または無償で提供することがあります。

第5条　外部のサービス

本アプリは、画面を出すために次のサービスにつながります。そのとき、それぞれのサービスに IP アドレスなどが届きます。

  • アプリの置き場所：GitHub Pages
  • 地図：OpenFreeMap
  • 文字：Google Fonts
  • プログラムの部品：jsDelivr
  • 本の情報：openBD、国立国会図書館サーチ（書名でさがしたときは、さがす言葉）
  • 住所から場所を調べる：国土地理院の住所検索（地図にない本屋を住所で知らせるときだけ。入れた住所）

営業時間や道順を Google マップで開いたときは、Google の決まりによります。

お店の X の投稿の表示：店のページの「いま行くと、出会えるもの」に、お店が X に「#本めぐり」を付けて投稿したものを、X の埋め込みで表示します。その投稿が画面に出たときに、X の部品を読み込みます（店のページを開いても、その欄まで見なければ読み込みません）。そのとき、X Corp. に IP アドレス・端末とブラウザの種類・表示したページ・X のクッキー（X にログインしている場合は、X のアカウントと結びつくことがあります）が届き、X の決まり（広告への利用を含みます）によって扱われます（X のプライバシーポリシー）。本アプリは、追跡しないよう X に頼む設定（dnt）を付けています。お店がスタンプに「X のアイコン」を選んだときは、そのアイコンを X（pbs.twimg.com）から読み込んで、スタンプの真ん中に出します（そのときも IP アドレスなどが X に届きます）。設定の「お店の X の投稿を表示しない」をオンにすると、X の部品もアイコンも読み込まず、X へのリンクだけを出します。

第6条　持つ期間

  • 参加の記録・読書と使い方の記録・出会った本の記録（世代・性別の記録をふくむ）・店の情報の報告：2年。過ぎたものは消します。
  • 引き継ぎコードで預かった記録：受け取ったとき、または24時間たったときに消します。
  • プロフィール：利用者がプロフィールの画面で「答えをすべて消す」をしたとき、または「記録をすべて消す」をしたときに消します（そのあと本アプリを使うときは、もう一度入れていただきます）。最後に送られてから2年たったものも消します。

第7条　送るのをやめたいとき・消してほしいとき

  • 参加の記録・読書と使い方の記録：本アプリを使うあいだは、いつも送ります（設定で止めることはできません）。送るのをやめたいときは、本アプリを使うのをやめてください。
  • プロフィール：プロフィールの画面で「答えをすべて消す」を押すと、運営者が持つ答えも消します（そのあと本アプリを使うときは、もう一度入れていただきます）。
  • 出会った本の記録は、端末の番号がつかないため、誰のものかわからず、あとから選んで消すことはできません。
  • 出会った本に世代と性別を添えるのをやめたいときは、設定の「出会った本に世代と性別を添える」で止められます。止めると、まだ送っていない分も送りません。すでに送った分は、誰のものかわからないため、選んで消すことはできません。
  • すでに送った参加の記録・読書と使い方の記録・報告を消してほしいときは、第9条のお問い合わせ先に、設定に出ている「端末の番号」を添えてご連絡ください。

第8条　安全のために

運営者は、届いた情報を、外から見られない場所に保存し、パスワードともう1つの鍵をかけた管理画面からだけ扱います。
